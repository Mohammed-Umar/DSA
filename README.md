# 🧠 Data Structures & Algorithms

A collection of my **Data Structures and Algorithms (DSA)** practice and **LeetCode solutions**, implemented primarily in **Python 3**.

This repository documents my problem-solving journey as I practice different algorithmic patterns, improve my coding skills, and prepare for technical interviews and competitive programming.

## 🚀 About

This repository contains solutions to problems from **LeetCode**, covering topics such as:

* Arrays
* Strings
* Linked Lists
* Two Pointers
* Hash Tables
* Searching
* Sorting
* Math & Number Theory
* Greedy Algorithms
* Basic Data Structures
* Problem-Solving Patterns

The goal is not only to solve problems, but also to understand the **logic, approach, and efficiency** behind each solution.

## 📂 Repository Structure

Each problem is organized into its own directory using the following format:

```text
DSA/
│
├── 1-two-sum/
├── 9-palindrome-number/
├── 14-longest-common-prefix/
├── 26-remove-duplicates-from-sorted-array/

├── 80-remove-duplicates-from-sorted-array-ii/

```

The folder name generally contains the **LeetCode problem number and problem title**.

## 💡 Approach

For each problem, I try to focus on:

1. Understanding the problem
2. Identifying the appropriate algorithm or pattern
3. Implementing the solution
4. Testing edge cases
5. Analyzing time complexity
6. Analyzing space complexity
7. Improving the solution when possible

## 📊 Complexity

I aim to consider both **time complexity** and **space complexity** for every solution.

For example:

```text
Time Complexity:  O(n)
Space Complexity: O(1)
```

As the repository grows, solutions may also include explanations and alternative approaches.
